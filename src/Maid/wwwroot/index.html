    Shared info

    Kept in the CLAUDE.md (and so the AGENTS.md) of every project in the list, and of every project added later, in a section of its own. Saving rewrites that section in all of them; save it empty to take it out again. The All projects session edits the same text as shared-info.md.

    Move to another folder

    Everything in the folder moves to the new one, which must not exist yet (or be empty); Claude Code's conversations of the project move along. Its sessions have to be stopped first.

    Rename a folder

    Click a folder in the path to rename one further up; every project in the list that is in it follows.

    Welcome to Maid

    All your Claude Code sessions in one window: each project runs in a terminal tile of its own, side by side.

    Get started

    1. Turn on Edit at the top right (Ctrl+Shift+E). Everything that changes the list waits behind it, so day to day the list only starts and stops sessions.
    2. Add a project folder: paste its path or pick it with Browse…, type a group if you like (none = Misc), then Add. Adding only lists it.
    3. Press next to the project. Claude Code starts in that folder, in a tile on the right.

    Running sessions

    • starts Claude Code. Press it again while one runs to open another session of the same project (#1, #2…).
    • starts it with --continue, picking up the last conversation in that folder.
    • stops a project's sessions (click twice to confirm). Clicking a row jumps to its sessions.
    • A tile whose session ended keeps its last screen and offers Launch, Resume and Close.

    What the dots say

    • Working on a prompt
    • Waiting for you
    • Ready for a prompt
    • Starting
    • Not running
    • Could not start

    "Waiting for you" means the turn is over or Claude asks something. A group's header sums up the projects inside it.

    Organising the list Edit

    • Projects go under groups of your own; in the list's header makes one, and groups can sit inside groups. Click a group to fold it.
    • Drag projects and groups to reorder them, or use the menus to rename, reorder or regroup them.
    • on a group's header writes its projects' terminal text in a colour, to tell them apart at a glance.
    • A project's menu can also move or rename its folder on disk; Claude Code's saved conversations follow it.

    Working across projects

    • All projects starts a Claude Code session about every listed project at once, in a folder of Maid's own. Use it for changes that span projects.
    • Shared info Edit is one text that Maid keeps in the CLAUDE.md of every listed project, and of each one added later.
    • Sessions can drive Maid as well: maidctl help in one of them lists what they can do (start, ask and watch the other sessions).

    What Maid does on your PC, so you know

    • Sessions run : Claude Code edits files and runs commands without asking first. Only add folders you are happy to let it work in freely.
    • Maid runs as administrator, and so do its sessions: Windows asks for permission when Maid starts.
    • Claude Code's "trust this folder?" question is answered Yes for you: you chose the folder by adding it.
    • When a session stops, the conversation (your prompts and Claude's replies, no tool output) is saved into the project's CLAUDE.md, in a marked section of Maid's own, so the next session knows what happened.
    • Every listed project gets an AGENTS.md with the same text as its CLAUDE.md (other coding agents read that one). An AGENTS.md that said something else is kept as AGENTS.maid-original.md.

    To change any of this, close Maid and edit : "command", "runAsAdmin", "autoTrust", "saveHistory".
